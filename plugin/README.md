# PSD Optimizer

这是针对 Photoshop UXP 重新实现的 PSD 清理插件，可在 Apple Silicon 原生模式运行，不需要让 Photoshop 进入 Rosetta 模式。

1.7.5 版只保留 Metadata、Empty Layers、Layer Styles 三项清理功能，以及“优化选中图层”和“优化当前文档”两个执行范围。Photoshop 插件列表图标和折叠面板工具栏图标使用相互独立的资源路径；折叠面板入口使用透明底扫把与三颗不等大的十字星芒，并为深色与浅色主题分别提供基础、`@1x` 和 `@2x` PNG，避免宿主因缺少显式 `@1x` 资源而回退为默认公文包占位图。覆盖开关使用独立高清对号资源，不依赖容易出现渲染偏差的 CSS 伪元素；标题栏说明入口改为圆圈内三个圆点。两个执行按钮采用一致的 100% 内容宽度与 40px 点击高度。说明页提供居中、等宽的 `English / 中文` 静态分段开关，不使用滑动动画；中英文文案区域采用固定尺寸，切换时界面元素不会位移，并记住上次选择。每次执行优化前会先清空上一条结果状态，再用本次新建的独立统计对象刷新数量和文件体积变化，不会跨操作累加。说明页内容不足时固定保持页脚分隔间距和底部留白，内容超过最小面板高度时允许垂直滚动。版本号与 `© 2026 CAVEMAN` 版权信息集中显示在说明页底部。不包含批量处理、账户、登录、试用或授权模块。

## 支持环境

- Photoshop 25.0 或更高版本
- 已在 Photoshop 2026（27.8）/ macOS Apple Silicon 原生模式完成真机验证
- 支持 PSD、PSB、PNG

## 安装

### macOS PKG（推荐）

1. 完全退出 Photoshop。
2. 双击 `PSD-Optimizer-1.7.5-macOS.pkg`。
3. 按 macOS 安装器提示完成安装。
4. 重新打开 Photoshop，在 `增效工具 → PSD Optimizer → PSD Optimizer` 中打开面板。

PKG 会直接安装并注册插件，适合在其他 Mac 上安装。

### UXP Developer Tools 备用安装

1. 打开 **Adobe UXP Developer Tools**。
2. 点击 `Add Plugin...`。
3. 选择本目录中的 `manifest.json`。
4. 在插件右侧菜单中点击 `Load`。
5. 回到 Photoshop，打开 `增效工具 → PSD Optimizer → PSD Optimizer`。

Developer Tools 加载方式需要让插件保持 `Loaded` 状态。

## 选项

- **元数据**：清空当前文档的 XMP 数据，并在 Photoshop 保存后安全写回文件。
- **空白图层**：调用 Photoshop 的“删除所有空图层”命令。
- **图层样式**：逐项移除已经关闭的图层效果，保留仍启用的效果；如果整组图层样式被隐藏，则移除该组内的全部效果。

“元数据”和“空白图层”是文档级操作，即使使用“优化选中图层”也会作用于整个文档；“图层样式”会遵循选中图层范围。

## 界面语言

- 点击标题栏的帮助图标进入说明页。
- 使用 `English / 中文` 静态分段开关切换整个插件界面；切换立即完成，不播放动画。
- 语言选择保存在本机，下次打开插件时继续使用上次选择。

## 优化结果

- 第一行显示完成状态、处理项目数量和保存位置。
- 第二行显示 `优化前体积 → 优化后体积 · 增减量（百分比）`。
- 无法读取源文件体积时，仍会显示优化后的文件体积，不会将未知值错误显示为 `0 B`。
- 每次点击执行按钮都会立即清空上一条结果，并在本次操作结束后整体刷新；各项数量和文件体积不会跨操作累加。

## 保存安全

- 默认不覆盖原稿，而是在原文件同目录生成 `文件名_fix.psd`；PSB 会生成 `文件名_fix.psb`，PNG 会另存为 PSD。
- 如果 `_fix` 文件已经存在，会依次生成 `_fix_2`、`_fix_3`，不会覆盖已有副本。
- 如果自动创建副本不可用，保存对话框也会拒绝把副本指向原文件路径。
- 打开“覆盖当前文档”后才会直接保存到当前文件。
- 每个文档的清理都在一个历史事务内执行；发生未处理异常时会回滚本次清理。锁定图层只在需要时临时解锁，并在结束或异常时恢复锁定。
- “优化选中图层”会记录开始时的图层 ID，文档级清理导致选区变化时不会误处理其他图层。
- 未选择“图层样式”时不会遍历、选择或解锁任何图层；空白图层统计由清理前后的真实图层 ID 差值计算。
