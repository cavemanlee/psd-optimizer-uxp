# PSD Optimizer 验证记录

- 验证日期：2026-07-28
- 版本：1.7.5
- 主机：macOS / Apple Silicon
- Photoshop：Adobe Photoshop 2026 27.8.0
- 运行模式：Apple Silicon 原生模式（未启用 Rosetta）

## 保留功能

| 项目 | 结果 | 证据 |
| --- | --- | --- |
| 元数据清空（内存） | 通过 | 写入有效 XMP 标记后清理，标记消失，统计值 `metadata: 1` |
| 元数据隔离复测 | 通过 | 27.8 运行时新建 64×64 临时文档，写入专用 XMP 标记后清理，`metadataMarkerWritten: true`、`metadataCleared: true` |
| 元数据保存（PSD 副本） | 通过 | 关闭并重新打开 `_fix.psd`，XMP 标记未恢复，文档保存状态为 `true` |
| 元数据保存（PSD 覆盖） | 通过 | 关闭并重新打开原 PSD，XMP 标记未恢复，文档保存状态为 `true` |
| 元数据保存（PNG 覆盖） | 通过 | 关闭并重新打开 PNG，XMP 标记未恢复，文档保存状态为 `true` |
| 空白图层删除 | 通过 | 空白测试层被删除，文字层与背景层保留，无警告 |
| 空白图层隔离复测 | 通过 | 27.8 运行时临时文档实际删除 1 个空白层，`emptyLayersRemoved: 1` |
| 隐藏图层样式 | 通过 | 关闭的 `patternFill` 被移除，启用的 `solidFill` 保留 |
| 样式筛选复测 | 通过 | 当前运行时输入关闭的阴影与启用的填色，结果仅删除关闭项：`hiddenStyleRemoved: 1`、`enabledStylePreserved: true` |
| 图层锁定恢复 | 通过 | 临时解锁的测试层在处理结束后恢复为全锁定 |
| 历史回滚 | 通过 | 事务中强制抛错后，测试修改未保留 |
| 原文档隔离 | 通过 | 临时自检关闭时不保存，并恢复原活动文档：`originalDocumentRestored: true` |

## 保存与界面

| 项目 | 结果 | 证据 |
| --- | --- | --- |
| 覆盖开关 | 通过 | “优化选中图层”和“优化当前文档”均读取同一个开关状态 |
| 覆盖勾选图标 | 通过 | 选中态使用独立 112×112 Retina 对号 PNG，在 14×14 勾选框内双向居中；不再使用可能被 UXP 裁切成时钟形状的 CSS 伪元素 |
| `_fix` 命名 | 通过 | 首个副本为 `_fix.psd`，同名存在时为 `_fix_2.psd`，原文件保持不变 |
| 副本路径保护 | 通过 | 路径比较会识别大小写及斜杠差异；备用保存路径与原文件相同时拒绝执行 |
| PSB 副本格式 | 代码检查 | PSB 未覆盖处理使用 `saveAs.psb` 并生成 `_fix.psb` |
| 保存失败保护 | 代码检查 | 新副本失败时关闭工作副本并删除本次未完成文件；原文档不被覆盖 |
| 功能范围 | 通过 | 清单、界面和运行时选项仅含元数据、空白图层、图层样式 |
| 执行范围 | 通过 | 只保留“优化选中图层”和“优化当前文档”；批量按钮、文件选择器和批量执行路径均已移除 |
| 插件名称 | 通过 | 清单名称和面板入口均为 `PSD Optimizer` |
| 反色选中态 | 通过 | 选中项使用蓝色背景与白色矢量图标，未选中项使用深色背景与灰色图标 |
| 高清图标 | 通过 | 三项功能、说明入口、覆盖对号和关闭按钮均由规范矢量母版生成 112×112 Retina PNG，不依赖字体符号 |
| 图标尺寸与对齐 | 通过 | 标题帮助图标和关闭图标均为 18×18，并使用无原生按钮皮肤的同行居中布局 |
| 说明入口图标 | 通过 | 标题栏入口改为圆圈内三个等距小圆点，不再使用问号 |
| Photoshop 插件列表图标 | 通过 | 插件列表使用独立的 `icon-*` 资源，并显示透明底小魔术棒 |
| Photoshop 折叠面板图标 | 通过 | 折叠工具栏入口改用独立的 `panel-broom-*` 路径与 `chrome` 类型；图形为用户确认的扫把剪影与左右分布的三颗十字星芒。深色与浅色主题均提供基础、显式 `@1x`（23×23）和 `@2x`（46×46）PNG |
| 执行按钮 | 通过 | UXP 运行时计算样式为内容区 `100%` 宽、40px 高、左右边距均为 `0px`；两个按钮均使用相同无原生皮肤控件 |
| 说明入口 | 通过 | 运行时只存在一个标题栏帮助入口，覆盖选项后的重复入口已移除 |
| 双语界面 | 通过 | UXP 运行时从 `en` 切换到 `zh-CN` 后标题同步变为“优化选项”，再次切换可恢复英文 |
| 语言记忆 | 代码检查 | 通过 `localStorage` 保存 `en` 或 `zh`，存储不可用时仍可在当前会话切换 |
| 语言模块排版 | 通过 | `English / 中文` 均为固定 50% 宽、25px 高的独立分段，文字使用双向 flex 居中；中文态不再依赖滑块坐标计算 |
| 语言切换性能 | 通过 | 已移除滑块元素、逐帧动画、计时器和位置测量；切换只更新文案与两个分段的静态选中态 |
| 双语布局稳定 | 通过 | 标题行、语言卡片、语言说明、切换轨道及三条功能说明均使用固定高度；中英文切换前后元素坐标保持一致 |
| 文件体积结果 | 通过 | 结果区独立显示优化前后体积、正负变化量和百分比；减少、增加、不变三种格式均已验证 |
| 结果独立刷新 | 通过 | 每次执行入口首先清空旧 `statusRenderer` 和结果文本，然后创建全新的统计对象；连续操作不会沿用或累加上一次数量 |
| 未知体积保护 | 通过 | 文件元数据读取失败返回 `null`，只显示可确认的优化后体积，不以 `0 B` 冒充原始体积 |
| 说明页底部留白 | 通过 | 说明文本与页脚分割线保留 16px 间距，页脚文本下方保留 8px 内边距，外层在最小面板高度允许垂直滚动，避免挤压重叠 |
| 面板尺寸 | 通过 | 首选尺寸为 230×360，最小尺寸为 200×320 |
| 版本与版权 | 通过 | 主面板不再显示版本；说明页底部显示 `PSD Optimizer · v1.7.5` 与 `© 2026 CAVEMAN` |

所有功能自检只使用运行时创建的临时文档和临时文件；结束后恢复用户原活动文档。元数据或空白图层单项处理不会遍历、选择或解锁图层；只有启用图层样式清理时才会临时处理相关锁定。移除的“画布外”“隐藏图层”“智能对象”和批量处理不再出现在界面、选项清单或执行路径中。
